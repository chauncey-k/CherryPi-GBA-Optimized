# 新卡制作与完整安装

适用于换新卡或系统分区损坏后的重装。已有正常卡请使用第二篇，只升级应用，不必重写整卡。

整卡写入会覆盖所选卡上的分区和内容。先把原卡的 ROM、BIOS、`.sav`、`.svs` 及 recovery 备份复制到别的介质。下文不包含恢复个人进度的数据。

## 1. 在 Windows 准备基础镜像

本独立目录自带本地 `firmware/sdcard-lcdtest-20261009.img.gz`，已由原有验证镜像压缩，未从 32GB 卡重新读取。Git 克隆不带此本地文件，需取得相同镜像或按构建文档重建。

在本项目根目录打开 PowerShell：

```powershell
python .\tools\verify.py --include-local
python .\tools\unpack-image.py
```

解压程序先验证压缩包，边解压边校验大小和 SHA256，成功后生成：

```text
firmware/sdcard-lcdtest-20261009.img
```

解压需要约321MiB空闲空间，不需要32GB。镜像大小336592896字节；SHA256：

```text
e794d49730c5fbefed9a83b815cce9737cfce71fd7b1ec99691e52cbddf23a89
```

## 2. 在 Windows 写入整张 SD 卡

沿用此前用过的 USB Image Tool（原工具来源记录：https://www.alexpage.de/usb-image-tool/download/）。

1. 将 SD 卡插入读卡器，启动工具，切到 **Device Mode**。
2. 根据读卡器名称和容量核对目标设备；不沿用以前的磁盘编号或盘符。
3. 点击 **Restore**，选择刚解压的 `.img`，确认目标卡后开始，等待完成且无错误。
4. Windows 如果要求格式化无法识别的 Linux 分区，选择取消。

Restore 是“镜像→卡”，Backup 是“卡→镜像”。普通复制 `.img` 文件到卡上不能替代整卡写入。

这一步写入了 SPL/U-Boot 及基础系统，不需要另外把模拟器写到 SD 卡扇区，也不需要 FEL 烧 Flash。

## 3. 创建 GAMES 分区并复制文件

基础镜像只含前两个分区：

| 分区 | 位置和大小 | 用途 |
|---|---|---|
| p1 / BOOT | 起始1MiB，大小64MiB | 内核、DTB、boot.scr |
| p2 / Linux | 起始65MiB，大小256MiB | 根文件系统 |
| p3 / GAMES | 从321MiB之后的剩余空间创建 | FAT32，ROM及安装文件 |

用 Windows“磁盘管理”在这张卡后面的**未分配空间**新建简单卷，选择 FAT32，卷标 GAMES。保留前两个分区。当前32GB卡剩余分区小于32GB；若没有FAT32选项或分区布局不符，先核对目标和写入结果，不改成 exFAT。

将本仓库 `sdcard-files` **里面的内容**复制到 GAMES 根目录。最终应当是：

```text
GAMES:/DISABLE_GBA_AUTOSTART
GAMES:/cherrypi-kit/packages/...
GAMES:/cherrypi-kit/kernel/...
GAMES:/roms/my-game.gba
GAMES:/gba_bios.bin
```

`my-game.gba` 换成自己准备的游戏；`gba_bios.bin` 由自己提供，大小16384字节。文件不随仓库分发。维护标记无 `.txt` 后缀。不要形成 `GAMES:/sdcard-files/cherrypi-kit` 这层多余目录。

## 4. 启动 Cherry Pi、更新已验证内核

安全弹出 SD 卡，插回板子。供电，连接现有 TTL 串口，115200 / 8N1 / 无流控，等 Linux 登录。用户名 root，基础镜像初始密码 cherrypi；输入密码时不回显。

以下所有 `sh` 命令在**板子串口的 Linux shell**执行，不是在电脑 PowerShell 执行：

```sh
mkdir -p /mnt/games /mnt/boot
grep -qs ' /mnt/games ' /proc/mounts || mount -t vfat /dev/mmcblk0p3 /mnt/games
grep -qs ' /mnt/boot ' /proc/mounts || mount -t vfat /dev/mmcblk0p1 /mnt/boot
cd /mnt/games/cherrypi-kit
sha256sum -c SHA256SUMS
cd kernel
sha256sum -c SHA256SUMS
```

挂载失败或校验不是全部 OK 就停止。内核校验成功后：

```sh
cp zImage /mnt/boot/zImage
cp suniv-f1c100s-generic.dtb /mnt/boot/suniv-f1c100s-generic.dtb
sync
reboot
```

重新登录，再挂载 GAMES 并检查硬件：

```sh
mkdir -p /mnt/games
grep -qs ' /mnt/games ' /proc/mounts || mount -t vfat /dev/mmcblk0p3 /mnt/games
grep -F 'cherrypi-gamepad' /proc/bus/input/devices
ls -l /dev/fb0 /dev/dsp
ls /sys/class/backlight/backlight
```

应能看到按键输入设备、显示、音频和背光。若不同，先处理硬件/内核问题，不用自动启动掩盖错误。

## 5. 安装运行库、音频工具和 BIOS

```sh
gzip -dc /mnt/games/cherrypi-kit/packages/gpsp-base.tar.gz | tar -xf - -C /root
gzip -dc /mnt/games/cherrypi-kit/packages/audio-tools.tar.gz | tar -xf - -C /root
cd /root/gpsp
sha256sum -c SHA256SUMS
cd /root/audio-tools
sha256sum -c SHA256SUMS
cp /mnt/games/gba_bios.bin /root/gpsp/gba_bios.bin
wc -c /root/gpsp/gba_bios.bin
/root/audio-tools/audio-mode dsp
```

BIOS应为16384字节。BusyBox tar 沿用 `gzip -dc | tar`，不要假设支持 `tar -z`。每段成功后才继续。

## 6. 按顺序安装启动、设置和主菜单

```sh
gzip -dc /mnt/games/cherrypi-kit/packages/autostart.tar.gz | tar -xf - -C /root
sh /root/cherrypi-autostart/install.sh
```

看到 Installed 后：

```sh
gzip -dc /mnt/games/cherrypi-kit/packages/settings-native.tar.gz | tar -xf - -C /root
sh /root/cherrypi-settings-native/install.sh
```

再安装独立主菜单：

```sh
gzip -dc /mnt/games/cherrypi-kit/packages/main-menu.tar.gz | tar -xf - -C /root
sh /root/cherrypi-main-menu/install.sh
```

这些中间包是明确的依赖链。它们的旧说明记录了当时状态，以本篇的最终顺序为准；此时还未安装最终优化版。

## 7. 最后安装本次优化程序

```sh
gzip -dc /mnt/games/cherrypi-kit/packages/optimized-20261017.tar.gz | tar -xf - -C /root
sh /root/cherrypi-profile/install.sh
sha256sum /root/gpsp/gpsp
```

最终应得到：

```text
923fb7fff27a3f0eb2bfc4b3599a62dd0149a478444ee8a521e49a563589f250
```

本包直接接受第6节的 native-settings 基线，不需要再经过以前的 savestate-fix、quick-menu、profile、smc-noop、smc-guards 等实验升级链。最终二进制已包含相应存档、快捷菜单、提示区分及优化改动。不要在最后一步后再安装旧包覆盖它。

## 8. 试运行并启用上电主菜单

先设置较低初始音量：

```sh
sed -i 's/^VOLUME=.*/VOLUME=25/' /etc/cherrypi-autostart.conf
/root/audio-tools/amixer -c 0 sset 'Headphone Source' 'DAC'
/root/audio-tools/amixer -c 0 sset 'DAC' 100%
/root/audio-tools/amixer -c 0 sset 'Headphone' 25% unmute
/root/gpsp/run-gpsp.sh "/mnt/games/roms/my-game.gba"
```

文件名要替换为实际文件名。通过实体按键验证游戏，退出回到 shell 后再启用自动启动：

```sh
rm -f /mnt/games/DISABLE_GBA_AUTOSTART
sync
reboot
```

正常应免登录进入主菜单。断开电脑后，仍可用方向键/A键选择游戏，退出回到主菜单，设置音量和亮度。

完整“空卡→全部重装”流程本次没有在备用实卡重新演练；镜像、内核和应用来自此前验证版本，包内校验与安装依赖已核对。本版优化程序及现有主菜单功能由用户实机确认。建议首次重装在备用卡演练，保留当前正常卡。
