# 已有系统升级与回退

适用于现在这张已经能启动主菜单、运行游戏的卡。当前版本已经是 `923fb7...f250`，可直接继续使用；整理目录并不要求再安装一次。

## 升级

正常关机后，在电脑把 `sdcard-files/cherrypi-kit` 复制到 GAMES 根目录，并创建空文件 `DISABLE_GBA_AUTOSTART`。插回上电，串口登录 root。

```sh
mkdir -p /mnt/games
grep -qs ' /mnt/games ' /proc/mounts || mount -t vfat /dev/mmcblk0p3 /mnt/games
pidof gpsp cherrypi-launcher
```

进程查询应无输出。然后：

```sh
cd /mnt/games/cherrypi-kit
sha256sum -c SHA256SUMS
gzip -dc packages/optimized-20261017.tar.gz | tar -xf - -C /root
sh /root/cherrypi-profile/install.sh
sha256sum /root/gpsp/gpsp
```

安装器只接受：本仓库的 native-settings 新装基线、上次 smc-guards 版本，或当前同一优化程序。其他版本会停止并输出 SHA256，不能靠删除校验代码强装。

本次整理使用独立备份目录 `/root/cherrypi-optimized-20261017/state/gpsp`，重复安装不覆盖首次备份。若安装前本来就是同一优化版本，备份和目标相同，回退也只是回到该版本。之前实验包的 `/root/cherrypi-smc-live/state/gpsp` 与此目录不同，不自动互相覆盖。

启用主菜单：

```sh
rm -f /mnt/games/DISABLE_GBA_AUTOSTART
sync
reboot
```

不必重写内核或 SD 卡。不改已有 BIOS、ROM、存档或设备设置。

## 回退

恢复维护标记、重新登录，确认两个进程均不运行后：

```sh
sh /root/cherrypi-profile/uninstall.sh
```

此命令恢复本整理包安装之前的模拟器。它不回退内核或其他历史包。确认正常后移除维护标记并重启。

## 可选采样

保持维护模式，在 shell 执行：

```sh
sh /root/cherrypi-profile/run-profile.sh
```

选择目标游戏，在相同场景运行约60秒，正常退出，再执行：

```sh
cat /tmp/cherrypi-profile.txt
```

`LIVE_SMC_RETAINED` 表示已支持的混音模板写入保留缓存的次数。正常上电不启用这个采样器。程序运行时占用串口，不能同时在同一终端输入调试命令；先退出再查看日志。

## 小体积备份

维护模式退出游戏后，备份 `/root/gpsp`、`/etc`、`/usr/local`，以及 GAMES 中的 ROM/存档到另一介质。既有 `recovery-20261015` 是用户之前某个时间点的快照，未自动收入本公开项目，也不是这次优化后的最新备份。整卡重写前先复制到其他盘。
