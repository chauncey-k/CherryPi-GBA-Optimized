# 当前版本与启动实测（2026-10-17）

当前板卡组合：既有 Linux 5.4.196 与 U-Boot 2022.01，gpSP ROM 文件映射版，fastboot stage1 r2 的设备树和启动参数，菜单更新为 Midnight Mint 主题与轻量动画版。没有重编 U-Boot 零倒计时，也没有更换内核 zImage。

## 当前入口与安装顺序

1. 新卡先按 [新卡制作与安装](01-新卡制作与安装.md) 安装基础镜像和 kit；已有运行系统按 [已有系统升级与回退](02-已有系统升级与回退.md) 确认发布基线。基础镜像仍只保存在本地，GitHub 不含整卡镜像。
2. 安装 [ROM 文件映射版](../experiments/rom-mmap-20261017/README.md) 的 `cherrypi-rom-mmap-20261017.tar.gz`。它保留 smc-live 音频指令优化，对原始 ROM 使用可回收的私有文件映射。
3. 安装 [fastboot stage1 r2](../experiments/fastboot-stage1-r2-20261017/README.md) 的 `cherrypi-fastboot-stage1-r2-20261017.tar.gz`。安装器接受 smc-live、24MiB 候选及 ROM 映射版的已知哈希，保留 gpSP。维护标记 `DISABLE_GBA_AUTOSTART` 必须是普通文件；同名文件夹会导致安装拒绝。只有看到 Installed 后才移除标记并重启。
4. 如需修复退出游戏时 LCD 闪现按键字符，可安装 [显示会话修复](../experiments/display-session-20261017/README.md)。此项与菜单安装相互独立。
5. 安装 [静态菜单主题](../experiments/theme-20261017/README.md) 的 `cherrypi-theme-20261017.tar.gz`。它接受 fastboot r2 菜单；无需封面图片。
6. 安装 [轻量动画菜单](../experiments/menu-motion-20261017/README.md) 的 `cherrypi-menu-motion-20261017.tar.gz`。它接受上一步静态主题或自身的哈希，不能直接跳过静态主题安装。用户已确认主题正常、动画效果良好。
7. 验证显示、GPIO 按键、音频、亮度、存档和退出回菜单。各包说明有独立备份与回退步骤。

原 kit 和 `components/gpsp` 仍对应原始 smc-live 基线；当前 gpSP 的对应源码在 `experiments/rom-mmap-20261017/source/gpsp`，当前菜单源码在 `experiments/menu-motion-20261017/source`；静态主题回退版本在 `experiments/theme-20261017/source`。封面预览暂缓使用，不是当前安装的前置步骤。历史实验保留用于对照，不应把所有候选包反复叠加安装。

## 板上启动实测

用户安装日志确认 SHA256 校验与安装成功；重启后命令行为：

```text
console=ttyS0,115200 loglevel=4 root=/dev/mmcblk0p2 rootfstype=ext4 rootwait rw panic=10
```

菜单记录：

```text
launcher_start 3.49
menu_ready 3.56
```

随后一次启动日志也确认 SPI NAND 不再探测；同一 Linux 时间基准下：

| 节点 | 优化前 | 优化后 |
| --- | --- | --- |
| framebuffer 就绪 | 约 3.28 秒 | 约 1.16 秒 |
| 开始运行 /sbin/init | 约 3.40 秒 | 约 1.29 秒 |
| GAMES 分区挂载日志 | 约 4.74 秒 | 约 2.62 秒 |

这些节点约提前 2.1 秒。用户主观反馈完整启动已是“几秒”；没有三次冷启动秒表数据，因此不发布精确总启动时间或平均值。

Linux uptime 不含 Boot ROM、SPL、U-Boot 与内核解压。U-Boot 中现有倒计时仍保留，内核读取日志约 723ms；不能将 menu_ready 3.56 秒写成完整上电耗时。菜单初始化到首帧约 70ms；按需扫描把 ROM 发现移至进入 Games，并不证明目录扫描本身变快。

## 验证范围与已知限制

- smc-live 基线改善了目标游戏音频自修改指令导致的翻译缓存抖动；原有实际 ARM 指令和八采样混音回归通过，用户板上确认卡顿改善。不同游戏性能不作统一保证。
- ROM 映射版已在板上运行，保留当前音频优化；文件映射能使干净 ROM 页可回收，但不是所有内存压力的保证性修复，长期压力测试仍需继续。
- 曾出现的精灵球交互退出已进一步定位为该特定 ROM 的无效文字指针，独立 ARM 指令核验可复现；不是凭 bad jump 就认定分页错误。修复工具只为严格匹配的原 ROM 生成副本。离线真实修复文件回放 300 帧通过，修复游戏的真机完整交互、背包数量及游戏内保存重读仍待反馈。
- 快速启动第一阶段已上板生效；启动前后的全部硬件回归不等同于已完成长期验证。尚未做 U-Boot 零等待或进一步内核配置裁剪。
- `experiments/*` 根 README 与本页记录后续结果；归档包内的 README 保留当时的候选说明和局限。

## 菜单动画验证

用户先确认静态主题界面正常，随后安装动画版并反馈效果良好。页面位移 8 像素/120 ms，高亮渐入 100 ms；动画定时重绘间隔 40 ms，结束后停止动画重绘；首页首帧直接显示。保留 fastboot 的首帧计时与按需扫描。上面的 3.56 秒来自此前 fastboot 菜单，尚未测量动画版的完整冷启动秒表数据。

ARMv5 构建和宿主 ASan/UBSan、快速输入/停止重绘、设置/启动游戏路径及安装回退测试通过。相对静态主题，ELF 的 data+BSS 增加 36 字节，没有新增全屏图像缓存。动画包卸载恢复静态主题；不要直接用较早 fastboot 安装包覆盖当前菜单。

## 发布与隐私边界

公开内容是源码、安装包、修复工具、说明及校验和。游戏 ROM、BIOS、`.sav`、`.svs`、私人修复安装包和本地基础镜像不提交 GitHub；`local/` 与相关扩展名在 `.gitignore` 中排除。修复包虽然是 `.tar.gz`，仍包含私人存档，必须保留在 `local/`。
